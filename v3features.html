Version 3 Features

Re-written from the ground up, SeeSpotBid v3 modernizes the app with a refreshed look and tons of new great features. SeeSpotBid is THE BEST app for searching eBay, and the best just got better.

What's New

Push Notifications on Multiple Devices - Get alerts on all your devices simultaneously so you never miss a deal.

eBay Warning Notifications - Get notified of any eBay warnings for saved searches (such as invalid categories).

New Search Filters - Add "Worldwide", "US Only", "Best Offer Only" and more filtering options.

Multi-Device Notifications (PRO) - Enhanced push notification support across all your devices.

Expanded Alert Types - Get alerts for new BIN, new auctions, AND expiring auctions (previously limited to one type).

Auto-Renewing Subscriptions - Switched to auto-renewing subscriptions for uninterrupted service (takes effect after your current subscription expires).

Smart Notification Text - Push notifications now specify BIN vs ending auctions in their text for clarity.

Clearer Workflows - Improved workflow when creating new saved searches.

New Help Page - Dedicated Help page for easier access to support resources.

Dark Mode - Added persistent Dark Mode option for comfortable viewing in any light.

Enhanced PRO Mode - "Fast Search" subscription is now "PRO" mode with many additional features.

More Frequency Options - New search frequency options including 12 and 24 hour intervals.

Postal Code by Search - Now supports separate postal codes for each saved search (previously user-wide).

Enhanced Watchlist - Watchlist page now shows number of new items instead of just a "new" indicator.

Password Change Screen - Easily update your account password for enhanced security.

Seller Management - Dedicated follow/exclude seller sections (no need to add them as keywords anymore).

Quick Seller Blocking - Shortcuts to listing page to quickly add a seller to your ignore list.

Great Features, Same Great Pricing

We've packed v3 with powerful new features to help you find the best deals faster. If you're a current v2 user, all your data will be automatically migrated. The best part? Pricing remains the same!

Get great features for free, or upgrade to PRO mode for an added edge when it comes to snagging the best deals, like faster search frequency and more search slots.
